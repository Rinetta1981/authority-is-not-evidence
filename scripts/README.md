# Experiment Scripts

This directory contains executable scripts used to run the experiments in **Authority Is Not Evidence**.

Experimental code will be organized sequentially so that the research pipeline can be reproduced from data construction through behavioral evaluation, mechanistic analysis, and alignment interventions.

Planned scripts include:

- candidate-item construction;
- baseline-answer screening;
- experimental-condition generation;
- behavioral pilot evaluation;
- confirmatory evaluation;
- model-organism fine-tuning;
- activation collection;
- probing;
- activation patching;
- circuit tracing;
- intervention evaluation;
- figure generation.
